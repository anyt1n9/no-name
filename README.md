# ソウルパス（仮）

ブラウザで遊べる「ローグライク × タワーディフェンス」ゲームです。地形カードで敵の通り道を自分で作り、タワーと英雄で城を守ります。

- 仕様書：[docs/spec.md](docs/spec.md)
- 現在の版：v0.1.4（1ステージの防衛戦が遊べる段階）

## 遊び方

1. **準備フェーズ**：土の道が敵の通るルートです。右側の地形カード（山・森）を選んでマップをクリックすると、道を変えられます。置く前に水色の線で変化を確認できます。全部使わなくても大丈夫です。
2. タワー（弓塔・火の塔・水の塔）を選んで、道の横に建てます。道の上には建てられません（敵のルートを変えられるのは地形カードだけです）。
3. 「戦闘開始」を押すと、左端の中央にある敵の城から魔物が攻めてきます。右端の中央にあるのが味方の城です。全5ウェーブを守り切れば勝ち、城HPが0になると負けです。
4. 英雄は3人（剣士・弓兵・魔法使い）います。右側の一覧をクリックすると出撃し、マップを**右クリック**した場所へ移動します。戦場に出せるのは1人ずつです。倒れたら15秒後に再び出撃でき、その間はほかの英雄に交代できます。「撤退」ボタン（Rキー）で城へ戻すこともでき、5秒休むとまた出撃できます。
   - 剣士：敵の前に立って足止めする
   - 弓兵：離れたところから矢で攻撃する（近づきすぎると敵に攻撃される）
   - 魔法使い：固まった敵にまとめて範囲魔法を撃つ（近づきすぎると敵に攻撃される）

| 操作 | 内容 |
|---|---|
| 左クリック | 地形を置く・タワーを建てる |
| 右クリック | 英雄を移動させる |
| 1〜3キー | タワーを選ぶ |
| Esc | 選択をやめる |
| R | 出撃中の英雄を撤退させる |
| Space | 一時停止 |

味方（英雄・タワー・味方の城）は青、敵（魔物・敵の城）は赤で表示されます。

URL の末尾に `?seed=123` のように付けると、同じマップを何度でも遊べます。

## 自分のパソコンで動かす

[Node.js](https://nodejs.org/)（バージョン22以上）を入れてから、次を実行します。

```bash
npm install
npm run dev
```

表示された URL（例：`http://localhost:5173/`）をブラウザで開くと遊べます。

## 開発用のコマンド

```bash
npm test            # 自動テスト
npm run typecheck   # 型チェック
npm run build       # 公開用ファイルを dist/ に作る
npm run check       # 上の3つをまとめて実行
```
